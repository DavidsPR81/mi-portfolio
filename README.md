# David Pérez Rodríguez - Portfolio V2 Pro 🚀

Bienvenido a la versión profesional (v2) de mi portfolio personal. Este proyecto ha sido diseñado y desarrollado siguiendo los estándares de UI/UX más avanzados para 2026, enfocado en proyectar mi perfil como **Full Stack Developer Junior**.

## 🌟 Características Pro
- **Diseño Ultra Moderno**: Estética basada en *Glassmorphism* y *Bento Grid* con una paleta de colores coherente y profesional.
- **Experiencia Interactiva**: Animaciones de alto rendimiento utilizando `Framer Motion` y seguimiento de cursor dinámico.
- **Optimización de Contenido**: Jerarquía visual clara que destaca mi trayectoria real (MediaMarkt → DAM → Full Stack).
- **Smart Tags**: Elementos flotantes que comunican especialidades técnicas de forma inmediata.
- **Consistencia Total**: Sistema de diseño unificado en todas las secciones con iconos decorativos y gradientes de alta gama.
- **Mobile First**: Totalmente responsive y optimizado para una navegación fluida en dispositivos móviles.

## 🛠️ Stack Tecnológico
- **Framework**: Next.js 13+ (App Router)
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Animaciones**: Framer Motion & React Icons
- **Despliegue**: Netlify

## 📂 Estructura del Proyecto
- `components/Hero.tsx`: Portada de alto impacto con tipografía editorial.
- `components/About.tsx`: Perfil profesional y aptitudes estratégicas.
- `components/Experience.tsx`: Timeline cronológico de carrera y formación.
- `components/Projects.tsx`: Showcase de soluciones digitales end-to-end.
- `components/Skills.tsx`: Dominio técnico y certificaciones de Google.
- `components/Contact.tsx`: Canal de comunicación profesional directo.

## 🚀 Instalación y Desarrollo
1. Clona el repositorio: `git clone https://github.com/tu-usuario/portfolio-v2.git`
2. Instala dependencias: `npm install`
3. Inicia el servidor de desarrollo: `npm run dev`
4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
